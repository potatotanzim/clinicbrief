Human review required. This example shows the intended drafting experience; it is not a live API result.
01 / SOURCE

Start with approved facts

Supply a UTF-8 text or Markdown file containing public administrative details. The AI prompt asks Claude to flag missing information.

02 / DRAFT

Choose your format

Request a FAQ, announcement, or website draft in English or Bangla through the Claude Messages API.

03 / REVIEW

Keep editing simple

Export Markdown and a printable HTML review sheet, with metadata that fingerprints the source.

No API key needed for the offline demo

Try it on your computer.

The offline demo preserves source text in a review sheet. It does not translate or generate AI copy.

git clone https://github.com/potatotanzim/clinicbrief.git
cd clinicbrief
python3 clinicbrief.py examples/clinic.md --demo

Open the generated review.html file. For AI drafting, set your Anthropic API key and an available model ID using the README instructions.

A focused first version.

Built for careful review.

This prototype drafts administrative communications. Every AI draft needs verification, including translations and factual details. Live API validation is still pending.

ClinicBrief currently runs locally. Hosted generation, user accounts, and appointment booking are not implemented.
